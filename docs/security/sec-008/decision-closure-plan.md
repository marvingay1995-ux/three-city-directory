Review order: agree reviewer criteria and candidate scope (D7-11), then obtain country/privacy prerequisites (D7-08/09), develop IAM and authority/consistency proof plans (D7-02/03) and duty rules (D7-05). Close custody, receipt and visibility design dependencies (D7-04/06/07), price and staff only after separate approval (D7-10), decide architecture (D7-01), then return for written adoption/next-scope decision (D7-12). Some proof requires separately authorized implementation. Record that dependency rather than marking it complete. Counsel decides law and flows; the security reviewer evaluates controls and evidence.
