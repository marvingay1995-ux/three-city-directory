# SEC-013 — Operator / accountability register

An operator is **not established** merely by the GitHub repository, prototype domain, product-owner identity or an intended visit/residence in Oman. Formal legal/operator facts must be recorded and verified before any application, contract, legal opinion or promotion.

## Minimum pre-counsel operator packet
The owner must supply an exact operator, jurisdiction and intended activity, audience/ages/languages, services/categories, what user data would be collected, all planned sources of revenue, expected public countries, providers, and true responsible persons. Verify any registration/licensing facts independently; do not upload personal ID documents into the repository.

**No operator or commercial licence is confirmed by SEC-013.** If the intended product differs materially from the PRD, stop and request explicit product-direction amendment instead of silently classifying it under the current general-business directory.
